// Built-in tools

🌐 Your public IP

IPv4 / IPv6

The address the internet sees for your connection. Select Details to see your provider and approximate location.

🧮 Subnet calculator

IPv4

Enter an address with a prefix (192.168.1.10/24) or with a netmask (192.168.1.10 255.255.255.0).

🔎 DNS lookup

DNS over HTTPS

Look up A, AAAA, MX, NS, TXT and other records for a domain. Choose PTR to look up an IPv4 address.

📇 WHOIS lookup

RDAP

Registration details for a domain: registrar, dates, status and name servers. An IP address shows its network owner.

📡 Latency check

HTTPS

Measures how fast a site responds from your browser, using 6 HTTPS requests. This is not an ICMP ping, so it includes a little server time.
